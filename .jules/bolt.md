## 2025-02-14 - Parallel API Fetching & Date Instantiation Optimization
**Learning:** In GitHub Action workflows using `actions/github-script`, running sequential `await` requests for independent API calls (such as `listCommits`, `pulls.list`, and `listForRepo`) introduces a major execution-time bottleneck due to API round-trip latencies. Grouping them with `Promise.all` allows parallel execution and significantly speeds up the workflow. Additionally, avoiding `new Date()` object recreation inside filter/loop callbacks by pre-calculating reference timestamps reduces unnecessary memory allocations and garbage collection overhead.
**Action:** Always inspect sequential await expressions in scripts. If they have no dependencies on each other, combine them using `Promise.all` and lift invariant instantiations (like date bounds) outside of iterative blocks.
